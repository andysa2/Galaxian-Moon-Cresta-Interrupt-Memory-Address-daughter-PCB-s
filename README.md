# Galaxian & Moon Cresta address and interrupt configuration daughterboards

These PCB's facilitate breaking out the Interrupt enable and Memory Addressing lines on Midway and Nichibutsu style arcade boards (also known as Galaxian Hardware).

Allows for the remapping of hardware to suit either Galaxian, Moon Cresta, Moon Alien, Moon Alien II or Moon Quasar firmware.

Once populated with the necessary components and pin headers, these PCB's replace the existing IC's  9N and 8E on the arcade board, then allowing for easy Interrupt and Address selection by way of DIP switches.

						Interrupt   Address
	Galaxian				5 	       4000
	Moon Alien				5	       4000
	Moon Alien II			4	       8000
	Moon Cresta				4	       8000
	Moon Quasar				4	       8000
